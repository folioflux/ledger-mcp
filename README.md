# ledger-mcp

Deterministic finance tools for AI agents over your own CSV bank exports. Same answer twice, with the rows behind every number. Local and read-only.

> **Status:** In development - not ready for use yet.

## What it will do

ledger-mcp will be a [Model Context Protocol](https://modelcontextprotocol.io) server that lets AI agents such as Claude, Cursor and Codex answer questions about your own bank CSV exports:

- Read CSV bank exports from your machine. Nothing is uploaded and files are never modified.
- Answer finance questions (totals, categories, recurring charges, period comparisons) with deterministic tools, so the same question gives the same answer every time.
- Cite the exact source rows behind every number, so each answer can be checked.
