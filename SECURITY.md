# Security policy

## Supported versions

This project is at an early stage. Security fixes are made on the `main` branch and in the latest release only.

## Reporting a vulnerability

Please do not report security problems in public issues, discussions or pull requests.

Report them privately in either of these ways:

- **GitHub private vulnerability reporting:** open the repository's **Security** tab and choose **Report a vulnerability**.
- **Email:** security@folioflux.com

Please include:

- a description of the problem and its impact,
- steps to reproduce it, or a proof of concept,
- the version or commit you tested, and your environment.

We will acknowledge your report, keep you updated while we investigate, and credit you in the fix notes if you would like. Please give us reasonable time to release a fix before you disclose the problem publicly.

## Scope

Never include real personal or financial data in a report. Use synthetic data to reproduce issues.
